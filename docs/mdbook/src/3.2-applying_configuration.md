# Applying a configuration

When a Node resource's configuration is changed (for example, by adding a patch in `spec.patches`), the `status.effectiveConfig` will no longer match the configuration deployed on the Node.

The operator will then detect that the node is out of sync and set the `NodeInSync` condition to `False`.

This condition can then be resolved in one of three ways:

1. Manually patching `{"operation":{"type":"Apply"}}` to the Node.
2. Manually patching `{"operation":{"type":"RollingApply"}}` to the Cluster, which will apply the configuration to all nodes in the cluster, one at a time, skipping any that are already in sync.
3. If [unattended configuration applies](./4.5-automated_upgrades.md) are enabled on the Cluster resource, the operator will automatically apply the configuration during the next maintenance window.
