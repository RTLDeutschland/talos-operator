# Kubeconfig and Talosconfig

Once a cluster is operational, the operator will create two Kubernetes Secrets in the same namespace as the cluster resource:

- `<metadata.name>-kubeconfig` containing an admin-context `kubeconfig` file for accessing the Kubernetes cluster, and
- `<metadata.name>-talosconfig` containing a `talosconfig` file for accessing the Talos API via `talosctl`

These secrets are regenerated once a day. The default lifetime of an admin `kubeconfig` is 1 year, [though this may be reduced using the `cluster.adminKubeconfig.certLifetime` machine configuration option](https://docs.siderolabs.com/talos/v1.11/reference/configuration/v1alpha1/config#adminkubeconfig).
