# Rolling reboots

A cluster may be rolling-rebooted by using the `RollingReboot` operation on the Cluster.

To initiate a rolling reboot using [kubectl-talos](./5.1-kubectl_plugin.md):

```sh
kubectl talos rolling-reboot CLUSTER
```

This will reboot all nodes in sequence. The operator will wait for each node to come back online and be healthy before proceeding to the next node.
