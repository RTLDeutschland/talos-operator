# Rolling configuration apply

A cluster may be rolling-updated with configuration changes by using the `RollingApply` operation on the Cluster.

To initiate a rolling apply using [kubectl-talos](./5.1-kubectl_plugin.md):

```sh
kubectl talos rolling-apply CLUSTER
```

This will apply the current configuration to all nodes in sequence. The operator will wait for each node to come back online and be healthy before proceeding to the next node.
