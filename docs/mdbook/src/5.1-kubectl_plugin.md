# kubectl plugin

The operator comes with a kubectl plugin that makes it easier to interact with operator resources and perform common tasks.

To install the plugin, run the following command (assuming Go is installed):

```bash
go install github.com/RTLDeutschland/talos-operator/cmd/kubectl-talos@latest
```

After installing the plugin, you can run `kubectl talos` to see the available commands:

```
$ kubectl talos
kubectl-talos is a kubectl plugin for interacting with Talos cluster resources managed by the Talos operator

Usage:
  kubectl-talos [command]

Available Commands:
  apply          Start an Apply operation on a Talos node
  bootstrap      Start a Bootstrap operation on a Talos node
  create         Create Talos resources
  help           Help about any command
  k8s-upgrade    Start a KubernetesUpgrade operation on a Talos cluster
  kubectl        Execute kubectl commands against the given operator-managed Talos cluster
  provision      Start a Provision operation on a Talos node
  reboot         Start a Reboot operation on a Talos node
  reset          Start a Reset operation on a Talos node
  rolling-apply  Start a RollingApply operation on a Talos cluster
  rolling-reboot Start a RollingReboot operation on a Talos cluster
  shutdown       Start a Shutdown operation on a Talos node
  talosctl       Execute talosctl commands against the given operator-managed Talos cluster

Flags:
  -h, --help               help for kubectl-talos
  -n, --namespace string   Kubernetes namespace
  -w, --watch              Watch the operation as it progresses (default true)

Use "kubectl-talos [command] --help" for more information about a command.
```

## kubectl talos kubectl

The `kubectl talos kubectl` command allows you to execute kubectl commands against the given operator-managed Talos cluster. This is useful for running kubectl commands without having to manually set up a kubeconfig file.

For example:

```bash
$ kubectl talos kubectl -n talos-ac athena -- get nodes
NAME                           STATUS   ROLES           AGE    VERSION
athena-c1   Ready    control-plane   110d   v1.35.0
athena-c2   Ready    control-plane   110d   v1.35.0
athena-c3   Ready    control-plane   110d   v1.35.0
athena-w1       Ready    <none>          110d   v1.35.0
athena-w2       Ready    <none>          110d   v1.35.0
athena-w3       Ready    <none>          110d   v1.35.0
athena-w4       Ready    <none>          110d   v1.35.0
```

## kubectl talos talosctl

Just as with kubectl, except it's using the talosconfig and talosctl binaries, so you can run talosctl commands without having to manually set up a talosconfig file:

```bash
$ kubectl talos talosctl -n talos-ac athena -- -n athena-c1.acme.internal get disks
```
